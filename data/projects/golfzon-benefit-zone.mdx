# Golfzon - Benefit Zone

골프존 모바일 앱 사용자의 리텐션을 제고하고, 다양한 혜택과 즐길 거리를 한눈에 직관적으로 제공하도록 혜택존의 구조와 시각 모션을 리뉴얼한 웹뷰 기반 프로젝트입니다.

## 🛠️ 기술 스택 (Spec)

- **Node.js**: `22.23.4`
- **Framework**: Vue.js `3.2.13`
- **Build Tool**: Vite `6.4.3` (Vue CLI / webpack 5에서 이관)
- **State Management**: Pinia
- **Platform**: 모바일 하이브리드 앱 웹뷰 환경

## 🚀 주요 역할 및 수행 내용

### 1. 혜택존 전면 개편

- 기존의 나열식 텍스트/리스트 위주의 투박한 구조에서 탈피하여 각 브랜드 및 미션 이벤트 성격에 적합한 섹션 카드 중심 레이아웃으로 UI를 리디렉션하여 가독성과 사용자 참여율을 극대화했습니다.

### 2. 스윙만보기 연동 스크롤 트랜지션

- 만보기 소개 페이지에서 스크롤 흐름에 따라 그래픽과 텍스트 카드가 리얼타임으로 교차 페이드하는 인터랙티브 가이드를 설계했습니다.
- **Intersection Observer API**와 Vue의 기본 `<transition>`을 결합하여, 모바일 단말기 자원을 최소화하면서도 정밀한 스크롤 연동 페이드 애니메이션을 구축했습니다.

### 3. 마일리지 미션 팝업 및 오늘 하루 보지 않기 구현

- **오늘 하루 보지 않기**: 로컬 스토리지 데이터 관리를 바탕으로 매일 하루 단위 팝업 기한을 계산하는 유틸 기능을 모듈화하여, 사용자의 앱 이용 피로도를 낮추었습니다.
- **마일리지 팝업 애니메이션**: 미션을 클리어한 사용자가 골프존 마일리지를 획득할 때, 생동감 넘치는 팝업의 모션 연출(Vue transition)을 지원하여 성취감(Gamification)을 자극했습니다.

### 4. Vue CLI → Vite 6 마이그레이션

`vue-cli-service`(webpack 5) 기반 빌드를 **Vite 6**으로 이관하고, 단일 `app.js`(약 1.8 MiB) 구조에 라우트·라이브러리 단위 코드 스플리팅을 도입했습니다. 상세 과정은 [Vue CLI → Vite 6 마이그레이션](/posts/vue-cli-to-vite-migration/)에 정리했습니다.

- `process.env.VUE_APP_*` define 치환, `require()` 변환, SCSS `@use` 자동 주입 등 Vue CLI 호환 레이어를 구성해 소스 변경을 최소화했습니다.
- webpack 폴리필(`global`) 의존 코드와 ESM 순환 참조 이슈를 정리하고, `vue.config.js`·`legacy/vue-cli/`로 롤백 경로를 확보했습니다.
- 프로덕션 빌드 중앙값 **19.43s → 7.57s (61% 단축)**, CSS 총량 **100.3 KB → 66.7 KB (33.5% 감소)**, 라우트 청크 13개 + 라이브러리 청크 7개로 lazy load를 적용했습니다.

### 5. 복권 긁기 랭킹 챌린지

2026년 8–9월에 복권 긁기 랭킹 챌린지를 혜택존 웹뷰에 추가했습니다.

- 시즌 오픈 팝업은 로컬 스토리지로 다시 보지 않기를 제어하고, 딤 영역 조작과 바텀 시트 뒤의 네이티브 스크롤을 막았습니다.
- 지난 시즌 결과와 참여 이력, 1,000위 초과 순위, 시즌이 없는 URL 진입 얼럿을 케이스별로 나눴습니다.
- 상단 광고 배너는 composable로 분리해 환경별 광고 코드를 재사용하고, 슬라이드가 하나일 때는 페이지네이션을 숨겼습니다.
- 메인에 이번 달 당첨자 팝업을 추가하고, 날짜 처리는 `moment`에서 `dayjs`로 교체했습니다.

### 6. 쇼핑·금융 혜택관 브릿지

- 쇼핑 전용관과 금융 혜택관으로 이어지는 브릿지 페이지를 추가했습니다.
- 혜택존 내부로 돌아오는 배너 링크는 `innerPush`로 연결해 웹뷰 이동이 앱 내비게이션 스택과 맞도록 했습니다.

### 7. 랭킹 챌린지 운영 어드민

같은 기간 `benefit-zon-admin-ui`(Vue 3, Vuex, Vuetify 3, Vue CLI)에 랭킹 이벤트 운영 화면을 넣었습니다.

- 이벤트 목록과 등록·수정 팝업에서 기간 겹침, 구간 중복, 이벤트명 24자 제한을 막아 중복 시즌이 등록되지 않게 했습니다.
- 랭킹 이벤트 상품 당첨 현황 페이지를 추가했습니다.
- 복권 수동지급, 복권 현황, 무료충전소, 미니게임 이용현황의 최대 조회 기간을 1개월로 제한했습니다.
- 파일 다운로드는 응답이 끝난 뒤 응답 헤더의 파일명을 사용하고, 중복 ZIP 로컬 헤더를 제거해 압축 해제 실패를 줄였습니다.
- 어드민 날짜 처리도 `moment`에서 `dayjs`로 맞췄습니다.
