# Golfzon - Mobile Coupon

골프존 앱 안의 모바일 쿠폰함과, 그 이용권을 발행·발송·정산하는 운영 백오피스입니다. 2025년 11월부터 앱에 쌓이는 쿠폰의 발행 조건, 발송 승인, 사용 현황을 화면에서 다룰 수 있도록 백오피스를 이어서 만들었고, 쿠폰함 웹뷰에서는 현장 사용 입력과 프로덕션 빌드를 맞췄습니다.

## 🛠️ 기술 스택 (Spec)

### 운영 백오피스 (`ticket-admin-ui`)

- **Framework**: Vue.js `3.2` (Composition API), Vue Router `4`
- **State**: Pinia `2`
- **UI**: Vuetify `3`, Vue Datepicker, Chart.js
- **Build**: Vue CLI `5` (webpack)
- **Events**: mitt

### 쿠폰함 웹뷰 (`ticket-front-ui`)

- **Framework**: Vue.js `3.2`, Vue Router `4`, Pinia `3`
- **Build**: Vue CLI `5`
- **Platform**: 모바일 하이브리드 앱 웹뷰
- 쿠폰함은 사용 가능·만료 탭과 상세(바코드, 번호 복사, 현장 확인코드, 예약·바로가기)로 구성됩니다.

## 🚀 주요 역할 및 수행 내용

### 1. 이용권 발행과 권종

발행 작성·상세·수정에서 사용 조건이 저장 전에 화면에만 반영되거나, 해제한 조건이 요청에 남는 경우를 막았습니다.

- 투비전 NX 제약을 **라운드 시스템** 제한과 드롭다운으로 바꾸고, 가맹 GDR·가맹 GRX는 사용 매장 제한과 매장 검색, 매장 확인 팝업으로 나눴습니다. 가맹 표기는 GDR에서 GRX로 맞췄습니다.
- 이벤트 2 선택, 외부제휴 이용권의 엑셀 쿠폰번호 등록, 쿠폰번호 중복 확인(타임아웃 180초), 일일 중복 사용 제한을 넣었습니다.
- 유효기간은 취득 시점·취득일 기준을 구분해, 취득 시점일 때는 만료일을 필수로 두지 않았습니다. 발행 후에도 정보를 수정할 수 있게 했습니다.
- 권종 관리에는 취소 가능 여부와 기본 이미지 등록 검사를 추가했습니다. 이미지 경로가 없거나 사용하지 않으면 이미지 API를 호출하지 않습니다.

### 2. 이용권 발송과 승인

- 발송 작성에 경품지급관리시스템 연동 키를 넣고, 현장 사용 라디오는 가맹 GRX에서 비활성화했습니다. 이미지가 없거나 형식이 다르면 저장 전에 알립니다.
- 승인 대기·발송 대기 건은 예약 취소가 가능하고, 승인 또는 반려 뒤에는 mitt로 승인 대기 목록을 다시 불러옵니다.
- 대상자 추가 팝업에 페이징을 넣었습니다.

### 3. 사용현황, 정산, 회원 보유

조회 기간이 길어 응답이 무거워지지 않도록 날짜 검색을 공통으로 제한했습니다.

- 날짜 프리셋과 유효성 컴포저블을 만들어 발송 내역, 발송 승인, 발행 승인, 발행 내역에 적용하고, 최대 조회 기간을 1년에서 **3개월**로 줄였습니다. 이용권별·발행별 사용현황과 지류 이용권 사용이력도 같은 제한을 둡니다.
- 이용권별 사용현황에는 사용대기 검색과 사용취소·미사용 전환을 추가하고, 상세의 유효기간 변경에서 잔여일 계산을 고쳤습니다.
- 회원 보유현황에 페이징, 엑셀 다운로드, 사용 상태, 권종 금액, 이용권별 수정 팝업을 넣었습니다.
- 정산은 월간 조회의 기본 시작을 전월로 두고, 기본·상세 조회마다 컬럼을 바꾸며 매장명·매장 코드를 보여 줍니다.
- 발행별 사용현황의 엑셀 다운로드는 CSV로 바꾸고, 쿠폰함 수신·사용 현황 받기를 추가했습니다.

### 4. 쿠폰함 웹뷰

쿠폰 상세에서 현장 직원이 확인코드를 입력할 때, iOS에서는 키패드가 하단 고정 팝업을 가렸습니다.

- `visualViewport`의 높이와 offset으로 키보드가 차지한 간격을 계산해, 바텀 팝업을 그 위로 올립니다. 뷰포트 resize·scroll 리스너는 팝업이 닫히면 제거합니다.
- 프로덕션 빌드에서는 devtool과 소스맵을 빼 배포 번들에 원본이 포함되지 않게 했습니다.
