# Golfzon - Plusshop

골프존 공식 모바일 앱 내에서 모바일 상품권, 스크린 아이템 등을 구매하고 선물할 수 있는 쇼핑 서비스인 '플러스샵'의 앱 웹뷰와 운영 어드민을 이어서 고도화했습니다.

## 🛠️ 기술 스택 (Spec)

### 앱 웹뷰 (`plusshop-front-source`)

- **Node.js**: `22.23.4`
- **Framework**: Vue.js `3` (Option API)
- **State Management**: Vuex `4`
- **Build Tool**: Vite `7.3.7` (Vue CLI에서 이관)
- **Platform**: 모바일 하이브리드 앱 웹뷰 환경

### 운영 어드민 (`plusshop-admin-ui-public`)

- **Framework**: Vue.js `2.6`, Vue Router `3`, Vuex `3`
- **UI**: Vuetify `2`

## 🚀 주요 역할 및 수행 내용

### 1. 하이브리드 웹뷰 인터랙션 성능 안정화

- 웹뷰 특유의 터치 반응 지연 현상을 억제하고 모바일에 가장 부드러운 스크롤 인터랙션을 위해 마운트 주기 단계에서 불필요한 재렌더링을 억제하였습니다.

### 2. 홀인원볼 자동결제 UI 고도화

- 사용자가 홀인원볼 상품의 자동결제 옵션(라디오 버튼 등)을 토글하거나 수정할 때, 즉각적이고 매끄럽게 밑에서 솟아오르는 슬라이드 모달 및 버튼 상태 값의 정밀 제어를 수행했습니다.
- 입력 선택 변화에 상응하여 버튼의 문구, 활성화 상태 변경 및 슬라이드 UI 간의 전환 트랜지션을 모바일 네이티브 앱 수준으로 매끄럽게 연동되도록 Vue reactivity를 설계하였습니다.

### 3. G패스 머니와 아이템 현장결제

- 골프존패스·마일리지 표기를 G패스 머니로 정리하고, 받은 선물과 전환 내역, 안내 페이지를 같은 명칭으로 맞췄습니다.
- 아이템 현장결제의 결제수단 등록·변경, 하단 버튼 sticky, 등록 완료 화면, 주문내역의 자동구매·현장결제 케이스를 추가했습니다. 결제 API는 v2 경로로 전환했습니다.
- 미수금이 남은 계정에서 해지를 시도하면 미납금 납부로 유도하고, 납부 완료 뒤에는 이미 등록된 결제수단이면 변경 화면으로, 없으면 등록 화면으로 이어지게 했습니다.

### 4. 홀인원볼 타겟과 코스 소개

- 홀인원볼 타겟 이벤트는 수량을 1개로 고정하고 선물하기를 숨겼으며, 일반 상품 상세에서는 타겟 상품으로 들어가지 못하게 했습니다.
- 코스 소개는 포스터에서 영상으로 넘기고, 슬라이드 이동이 끝난 뒤에 재생되도록 전환 속도를 맞췄습니다.

### 5. 미납금 납부와 G멤버십 1회 이용권

- 미수금 결제 페이지와 납부 완료 화면을 추가하고, 현장결제 메인에서 미수 여부를 확인해 정산 팝업을 띄웁니다.
- AI 코스매니저 이벤트 페이지에서 체험권 유무, G멤버십 프리미엄 이상 안내, 리포트 이미지를 나눠 보여 줍니다.
- G멤버십 1회 이용권 기간에는 상품 상세 하단 버튼과 현장결제 메인의 문구·이미지를 그 상품에 맞게 바꿉니다.
- G멤버십 가입 유도 페이지를 추가하고, 장착 성공·실패는 토스트로 알립니다.

### 6. Vue CLI → Vite 7 이관

2026년 10월 말 앱 웹뷰 빌드를 Vue CLI에서 **Vite 7**로 옮겼습니다.

- `require()` 호출, 환경 변수, 루트에 중복되던 `App.vue`를 정리하고 카테고리 값을 환경별로 적용했습니다.
- 웹뷰 재배포가 옛 번들에 갇히지 않도록 캐시 가드를 넣었습니다.

### 7. PG 정산과 미수 어드민

`plusshop-admin-ui-public`에는 결제 운영 화면을 추가했습니다.

- PG 결제 현황, 일별 정산, 내역별 통계와 영수증 보기를 넣고, 마일리지 표기는 골프존패스 포인트로 맞췄습니다.
- 멤버십 1회 이용권 미수현황에서 변제 완료, 관리자 회수, 해지 사유, 매장명을 구분해 보여 주고 상세에서 회수 처리가 목록에 바로 반영되게 했습니다.
- 공휴일 관리 화면을 추가하고, 등록된 날짜는 수정하지 못하게 했습니다.
- 넓은 표는 셀 줄바꿈 없이 테이블 안에서 가로로 스크롤됩니다.
